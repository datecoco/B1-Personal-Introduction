# B1 Personal Introduction

순수 HTML, CSS, JavaScript로 만든 반응형 자기소개 웹페이지입니다.
웹 기초 학습을 위해 HTML 구조, CSS 반응형 디자인, JavaScript 이벤트 처리와 GitHub API 연동을 직접 구현했습니다.

## 사용 기술

- HTML
- CSS
- JavaScript
- GitHub REST API
- GitHub Pages

## 주요 기능

- 반응형 네비게이션과 햄버거 메뉴
- 다크 모드 전환 및 localStorage 저장
- 부드러운 스크롤
- 스크롤 위치에 따른 헤더 변화와 맨 위로 버튼
- Intersection Observer를 활용한 섹션 등장 효과
- 이름, 이메일, 메시지 입력 검사
- GitHub API를 이용한 공개 저장소 프로젝트 카드 표시
- 로딩, 오류, 빈 결과 상태 표시

## 실행 방법

1. 프로젝트 폴더를 VS Code에서 엽니다.
2. `index.html`을 Live Server로 실행합니다.
